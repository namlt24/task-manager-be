--------------------------------------------------------------------------------
C. RATE-LIMIT ĐĂNG NHẬP (Redis, KHÔNG Bucket4j)
--------------------------------------------------------------------------------
- security/RateLimitFilter (OncePerRequestFilter, thêm trong SecurityConfig qua
  addFilterBefore): chặn brute-force cho POST /v1/auth/{login,register,
  forgot-password,reset-password} theo IP (header X-Forwarded-For ưu tiên, fallback
  remoteAddr) bằng Redis fixed-window (INCR + EXPIRE). Vượt ngưỡng → 429
  ProblemDetail + header Retry-After. FAIL-OPEN nếu Redis lỗi.
- Cấu hình AppProperties.RateLimit (app.rate-limit.enabled/auth-requests=10/
  window-seconds=60).
- Verify: 10 request đầu qua, từ request 11 → 429 + Retry-After.

--------------------------------------------------------------------------------
D. CACHE REDIS (categories/labels)
--------------------------------------------------------------------------------
- config/CacheConfig (@EnableCaching + RedisCacheManager, TTL 30', JSON value).
  Dùng ObjectMapper.copy() + default typing EVERYTHING để record DTO round-trip
  đúng (không thành LinkedHashMap).
- CategoryService/LabelService: @Cacheable(cacheNames="categories"/"labels",
  key=userId) trên list(); @CacheEvict trên create/update/delete.
  (Ở M1 key đổi sang @workspaceAccess.currentWorkspaceId().)
- Verify: GET tạo key categories::{uid}; create → evict; GET lại repopulate.

--------------------------------------------------------------------------------
E. HARDENING
--------------------------------------------------------------------------------
- SecurityConfig headers: X-Frame-Options: DENY, X-Content-Type-Options: nosniff,
  Referrer-Policy: same-origin, HSTS (chỉ phát qua HTTPS).
- application.yml: server.error.include-message/stacktrace/binding-errors: never.
- ĐỔI PUBLIC_MATCHERS → AntPathRequestMatcher (servlet-path based) thay cho
  MvcRequestMatcher mặc định — tránh lỗi không match /v1/auth/** trong
  @SpringBootTest (nguyên nhân test register bị 401).

--------------------------------------------------------------------------------
F. TEST TESTCONTAINERS
