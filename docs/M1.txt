A. MỤC TIÊU M1

C. BACKEND — module workspace
--------------------------------------------------------------------------------
- Entities Workspace/WorkspaceMember + enum WorkspaceRole; repos.
- WorkspaceContext (ThreadLocal) + WorkspaceContextFilter (@Component, đọc header
  X-Workspace-Id).
- WorkspaceAccess (bean workspaceAccess):
  * currentWorkspaceId() (header → fallback workspace cá nhân, VERIFY membership).
  * requireManager()/requireOwner() (+ biến thể ...Of(id) cho endpoint mang id ở path).
  * isMember(wsId,userId), roleOf(wsId,userId).
- WorkspaceService/Controller:
  GET/POST /v1/workspaces, GET /v1/workspaces/{id}/members,
  PATCH .../members/{userId}/role (OWNER), DELETE .../members/{userId} (OWNER);
  provision(userId,name) tạo workspace + OWNER (gọi khi REGISTER).
- AuthService.register → tạo workspace "Cá nhân" + OWNER.
- REFACTOR SCOPE TOÀN BỘ (user_id → workspace_id + role): board/category/label/
  note/task service+repo dùng findByWorkspaceId...; TẠO/SỬA/XOÁ board/cột/danh mục/
  nhãn cần MANAGER; task CRUD cho mọi member (M1; siết theo assignee ở M3). Child
  theo task (subtask/attachment) validate taskRepository.findByIdAndWorkspaceId;
  time-entry vẫn theo user nhưng task phải thuộc workspace; REPORT scope workspace
  (ReportRepository native đổi user_id→workspace_id). Cache categories/labels đổi
  key → @workspaceAccess.currentWorkspaceId().
- Common: ForbiddenException (403) + handler.
